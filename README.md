## 📄 Documentation
Documentation about how to use/configure jajoptak (Leaf): [Leaf Docs](https://www.leafmc.one/docs/getting-started)

## 📦 Building
Building a Paperclip JAR for distribution:
```bash
./gradlew applyAllPatches && ./gradlew createMojmapPaperclipJar
```
